#  Text Editor Web App

A professional browser-based text editor inspired by Microsoft Word and WPS Office. This application is built entirely with **HTML5, CSS3, and Vanilla JavaScript**, offering a clean and responsive interface for creating, editing, formatting, saving, and exporting documents without any backend or external database.

##  Features

* Modern Microsoft Word/WPS-inspired interface
* Rich text editing with live formatting
* Font family, font size, and text styling
* Bold, Italic, Underline, and Strikethrough
* Text color and highlight color
* Paragraph alignment and spacing
* Bulleted and numbered lists
* Insert images, tables, links, emojis, and symbols
* Undo and Redo functionality
* Find and Replace
* Word and character counter
* Auto Save using LocalStorage
* Keyboard shortcuts
* Custom context menu
* Light and Dark themes
* Zoom controls
* Responsive design for desktop, tablet, and mobile
* Print documents
* Export as TXT, HTML, Markdown, JSON, and PDF
* Import text and HTML files
* Fullscreen editing mode
* Browser spell check support

##  Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript (ES6)
* LocalStorage API
* jsPDF (PDF Export)
* html2canvas (Optional PDF/Image Support)
* Font Awesome Icons
* Google Fonts



##  Getting Started

1. Download or clone the project.
2. Open the project folder.
3. Launch `index.html` in your preferred web browser.
4. Start creating and editing documents instantly.

No installation or backend setup is required.
